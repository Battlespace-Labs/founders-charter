# Claude Code instructions

Follow [`AGENTS.md`](AGENTS.md) as the controlling cross-agent operating
contract.

Claude may be invoked from issues or pull requests for implementation,
analysis, critique, or review. Determine which role the request actually asks
for before changing files.

- For analysis or review, report findings without modifying the branch unless
  explicitly asked to implement them.
- For implementation, use a `claude/` branch and a draft pull request.
- Read the governing doctrine, foundation, dossier, schema, or inventory before
  editing its dependents.
- Preserve ambiguity and competing interpretations when the record does not
  authorize a single conclusion.
- Do not adopt, retire, supersede, delete, or materially reinterpret doctrine
  without Patrick's explicit confirmation.
- Do not commit credentials or reproduce secret values in comments, logs, or
  artifacts.
- Validate the complete diff and report what was checked.

If instructions conflict, stop and identify the conflicting sources rather
than silently choosing one.
